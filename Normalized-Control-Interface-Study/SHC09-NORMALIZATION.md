# SHC09 归一化方案分析

## 1. 当前 DEV 的真实定义（只读核对）

`src/Aircraft/SHC09/Aerodynamics/shc09_control_surface_geometry.m`：

```text
φ_i = 0,60,…,300°
B_M = [−cosφ; −sinφ; 1]                     (3×6, 无量纲)
```

`shc09_control_surfaces.m`：

```text
B_tau = d_cs · Ve² · diag([l1,l1,l2]) · B_M
M_cs  = B_tau · δ
```

参数（`shc09_parameters.m`）：`d_cs=0.0032`，`l1=0.267 m`，`l2=0.066 m`，
六舵生效行程 ±40°（±0.698132 rad），六舵同一行程。

`shc09_hover_equilibrium.m`：

```text
T = m·g,  Ω = sqrt(T/k_T0),  Ve = sqrt(T/(sd·ρ·S))
M_fan = −k_Q0·Ω²,  M_sta = +k_sta·Ve²
δ_trim = −(M_fan+M_sta) / (6·d_cs·Ve²·l2)
```

因此 `B_tau·(δ_trim·1_6) = [0;0;−(M_fan+M_sta)]`，物理配平偏航力矩
`0.094923 N·m`（由 6 片舵面共同产生）。

悬停数值（合成气动 fixture，与真实数据无关）：

```text
Ve = 24.230354923 m/s
δ_trim = 0.127587337 rad = 7.3102°
cond(B_tau) = 2.8606, rank = 3
B_tau = （行：roll, pitch, yaw；列：CS1..CS6，N·m/rad）
  −0.501627  −0.250813   0.250813   0.501627   0.250813  −0.250813
   0.000000  −0.434422  −0.434422   0.000000   0.434422   0.434422
   0.123998   0.123998   0.123998   0.123998   0.123998   0.123998
```

修正：必须区分**绝对力矩**与**相对配平的力矩增量**。

- 绝对力矩 `B_tau·δ`（以零力矩为基准）的单轴范围为
  `±[1.4008, 1.2131, 0.5194] N·m`（滚转/俯仰/偏航，各自独立、忽略耦合）。
- DEV 的 Rate PID 输出是相对配平的 `τ_rel = B_tau·(δ−δ_trim)`；六舵共同
  配平 `δ_trim = 0.127587 rad` 不参与该增量。偏航方向：
  - 正向可达 `+0.424477 N·m`（`δ_i = +δ_max`）；
  - 负向可达 `−0.614323 N·m`（`δ_i = −δ_max`）。
  因此相对偏航权限是**非对称**的；绝对范围看起来对称，但围绕的是零力矩，
  不是配平点。
- 按 `S=diag(1.165752, 1.165752, 1.925298) 1/(N·m)` 映射：
  `ν_yaw ∈ [−1.182755, +0.817245]`；`ν_yaw=1` 在正方向不可达，
  `ν_yaw=−1` 才落在负向权限内。滚转/俯仰 `ν ∈ ±[1.633, 1.414]`。
- 所以 `ν∈[−1,1]` 既不是绝对满舵，也不是相对配平的满权限；它只是 PX4
  伪逆列统计尺度的数值区间。

## 2. 归一化执行器尺度 `U`

六舵同一 ±40°：

```text
u_i ∈ [−1,1],  δ_i = δ_max·u_i,  δ_max = 0.698131701 rad
U = δ_max·I_6
B_u = B_tau·U                       [N·m per 单位 u]
```

`u_trim = δ_trim/δ_max = 0.182755`（六舵相同）。

## 3. PX4 式固定尺度 `S`

按 `ControlAllocationPseudoInverse` 的公式对 `B_u` 求：

```text
M = pinv(B_u)
S = diag(1.165752149, 1.165752149, 1.925297848)   [1/(N·m)]
S⁻¹ = diag(0.857815, 0.857815, 0.519400)         [N·m per 单位 ν]
```

含义：

- `ν_roll=1` 对应约 0.858 N·m 的滚转**相对配平**力矩增量；
- `ν_yaw=1` 对应约 0.519 N·m 的偏航相对增量，但该值超过正向可达的
  0.424477 N·m，故 `ν_yaw=1` 不可达；负向可到 `ν_yaw≈−1.183`；
- 该 `S` 由 `B_u` 的伪逆列统计得到，**不是**“满舵力矩”或“±40° 对应 ±1”的物理限幅；
- 绝对力矩范围是 `±[1.4008, 1.2131, 0.5194] N·m`；相对配平范围是
  `roll/pitch ±[1.4008, 1.2131]`、`yaw [+0.424477, −0.614323] N·m`；
- 因此 `ν∈[-1,1]` 不是执行器全行程，也不是相对配平的满权限。

## 4. 三种方案对照

### 方案 A：物理量接口（当前）

```text
Rate PID → τ [N·m] → PINV(B_tau) → δ [rad]
```

- 控制器、分配器、日志全部 SI；
- 与 PX4 的差别只在“控制空间”是 N·m 而非归一化 ν；
- 积分限幅、力矩限幅、残差均为 N·m，科研解释直接；
- 更换机型时 `B_tau` 与执行器范围变化，控制器增益需按物理对象重调（本来就应重调）。

### 方案 B：固定尺度归一化

```text
Rate PID → ν = S·τ [无量纲] → PINV(B_u)·S⁻¹ → u [−1,1] → δ=U·u
```

- 选 `S` 固定（例如按悬停 `B_u` 计算一次）；
- 控制器增益需做 `Kp_ν=S·Kp_τ` 等换算，否则闭环增益改变；
- 无饱和、满秩、均匀 `U` 时与方案 A **逐元素等价**（本次数值误差 <1e-15 rad）；
- 饱和时 `u` 裁剪与 `δ` 裁剪等价（`U` 均匀），残差 `ν_res=S·τ_res`；
- 需要额外记录 `S`、`U`、`ν` 才能保持物理可解释性；
- 机型更换时 `S` 变化，控制器若用 ν 增益需要同步换表。

### 方案 C：动态尺度归一化

```text
S(Ve) = S0·(Ve0/Ve)²
Rate PID → ν = S(Ve)·τ → ...
```

- 瞬时映射仍可精确（把 `S(Ve)` 代入分配器）；
- 但同一物理 `τ` 需要的 `ν` 随 `Ve²` 变化；固定 `Kp_ν` 会使物理环路增益
  随 `Ve²` 变化，等价于增益调度；
- SHC09 的 `B_tau∝Ve²`，`Ve` 又随推力/轴向气流变化；没有增益调度或物理 τ 接口时，
  动态 S 会改变闭环稳定性，不能当作“仅归一化”；
- 若分配器使用 `B(Ve)` 但 `S` 固定，物理映射仍精确，且控制器物理增益不变；
  这是比“动态 S”更稳妥的选择。

## 5. 出口流速与配平

- `B_tau` 与 `Ve²` 成正比。DEV 当前 `pinv_allocator` 用**指令推力**按名义涵道模型
  计算 `Ve_nom`，不读取真实瞬时出口流速；这是允许的名义模型。
- 配平舵角 `δ_trim` 随 `Ve` 与 `M_fan` 改变；归一化接口必须显式携带 `u_trim`，
  否则零控制指令会变成零舵角，破坏悬停配平。
- 方案 B 中 `ν=0` 必须映射到 `u_trim`（即 `δ_trim`），不能映射到 `u=0`；
  `control_trim` 与 `actuator_trim` 的区别必须保留。

## 6. 电机独立归一化

```text
T = k_T0·Ω²,  T ∈ [0, T_max],  T_max = k_T0·Ω_max² ≈ 41.7 N（Ω_max=1200）
u_m = T/T_max ∈ [0,1]（可选）
B_rotor = [0;0;−T_max]（FRD，推力沿 −z）
```

- 电机与六舵面是不同物理通道：电机给力，舵面给力矩；
- 可以定义独立的标量归一化推力 `u_m`，其参考 `T_max` 必须由机型/设备给出；
- 不能把 `u_m` 与六舵 `u` 拼成 7 维统一求解器；
- 若未来需要推力归一化 Topic，应单独声明 `thrust_n` 与 `T_max`，并保留 Ω 命令。

## 7. SHC09 的归一化结论

1. 当前六舵 `U` 均匀，方案 B 与方案 A 在数学上**可精确等价**；
2. `S` 是 PX4 式条件化尺度，不是物理限幅；不能宣称 `ν∈[−1,1]` 就是满舵；
3. 建议若引入归一化，使用**固定 S**（按悬停 `B_u` 标定），并保留 N·m 主接口；
4. 不建议使用动态 `S(Ve)`，除非同时实现增益调度与闭环验证；
5. 配平、出口流速名义模型、电机独立推力必须显式保留。
